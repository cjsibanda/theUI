# Carousel 1 React

A reusable and responsive carousel component built with React

The component features:

* Dynamic slide rendering using React props
* Previous and next navigation buttons
* Dot navigation indicators
* Auto-play functionality
* Responsive design for desktop, tablet, and mobile devices
* Modern gradient-based UI styling
* Reusable architecture suitable for integration into larger React applications

## Preview

![Carousel UI](./images/carousel_react.png)

## Technologies Used

* React
* JavaScript (ES6+)
* CSS3

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```
