# Carousel Component (Vanilla JavaScript)

A responsive and reusable carousel component built using:

- HTML5
- CSS3
- Vanilla JavaScript

## Features

- Responsive design
- Smooth slide transitions
- Previous and Next navigation
- Auto-play functionality
- Navigation dots
- Styled call-to-action buttons
- Easily customizable slides

## Running the Project

Start a local development server:

```bash
npx serve .
```

Then open:

```text
http://localhost:3000
```
