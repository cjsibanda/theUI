# Products Grid Component

Sibanda design reusable ecommerce product grid component built with:

- HTML
- CSS
- Vanilla JavaScript

## Features

- 6 reusable product cards
- Responsive CSS Grid layout
- Desktop: 3 columns
- Tablet: 2 columns
- Mobile: 1 column
- Hover animations
- Interactive Add button
- Clean modern UI
